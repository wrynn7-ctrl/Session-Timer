# Code walkthroughs

One document per file that someone wrote or changed for Session Dial. Each one goes through the
file from top to bottom and says what every piece does and why it is there.

Start with `index-html.md`. It covers the timer itself; everything else exists to wrap, build or
test that one page.

## The app

| Document | File it explains | In one line |
|---|---|---|
| [index-html.md](index-html.md) | `www/index.html` | The whole timer: layout, styling and logic. |
| [SaveFilePlugin.md](SaveFilePlugin.md) | `android/app/src/main/java/com/sessiondial/app/SaveFilePlugin.java` | Opens Android's "save as" screen for Export CSV. |
| [MainActivity.md](MainActivity.md) | `android/app/src/main/java/com/sessiondial/app/MainActivity.java` | The app's entry point on Android. |
| [AndroidManifest.md](AndroidManifest.md) | `android/app/src/main/AndroidManifest.xml` | What the app is and which permissions it asks for. |
| [icon.md](icon.md) | The launcher icon files under `android/app/src/main/res/` | The dial icon, in the forms different Android versions need. |
| [capacitor-config.md](capacitor-config.md) | `capacitor.config.ts` | App name, app ID and where the web page lives. |

## Files with no document of their own

These are generated by tools or are standard boilerplate. Nobody edits them by hand, so there is
nothing project-specific to walk through.

| File or folder | What it is |
|---|---|
| `www/capacitor.js` | Capacitor's browser library. `scripts/copy-libs.js` overwrites it on every `npm install`. |
| `www/fonts/` | The Instrument Sans and Instrument Serif font files. |
| `android/app/src/main/res/raw/` | `chime_wind.wav` and `chime_end.wav`, the two notification sounds. |
| `package-lock.json` | The exact version of every library, written by npm. |
| `android/gradlew`, `gradlew.bat`, `gradle/wrapper/` | The Gradle launcher. It downloads the right Gradle version by itself. |
| `android/settings.gradle`, `capacitor.settings.gradle`, `app/capacitor.build.gradle` | Lists of plugin sub-projects. `npx cap sync` rewrites the two `capacitor.*` files. |
| `android/gradle.properties`, `app/proguard-rules.pro` | Default build settings from the Capacitor template. |
| `android/app/src/main/res/values/strings.xml` | The app name as Android shows it ("Session Dial"). |
| `android/app/src/main/res/values/styles.xml`, `layout/activity_main.xml`, `drawable*/splash.png` | The template's theme, empty layout and splash image. |
| `android/app/src/main/res/xml/file_paths.xml` | Which folders the share sheet may hand files from (used only by the export fallback). |
| `android/app/src/main/res/drawable/ic_launcher_background.xml` | Template leftover; the icon no longer uses it. |
| `android/app/src/test/`, `src/androidTest/` | The template's two example tests. They test nothing about this app. |
| `.gitignore` files | Keep `node_modules`, build output and APKs out of the repo. |

Line numbers in these documents are approximate and will drift as the code changes. Each section
also names a comment or function you can search for.
